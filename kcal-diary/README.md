# 熱量日記（v1.2）

個人專屬的每日熱量紀錄 PWA。純前端，不需要伺服器或帳號，資料只存在使用者自己的瀏覽器（localStorage）。
**除了選用的 AI 拍照辨識以外，所有功能都免費。**

## 功能
- **個人設定**：依性別、年齡、身高、體重、活動量，以 Mifflin-St Jeor 公式計算 BMR、TDEE 與每日目標；可選減重／維持／增肌，或自訂目標。
- **今日**：熱量環形圖、剩餘熱量、蛋白質／碳水／脂肪進度；分早餐、午餐、晚餐、點心記錄；可切換日期補登。
- **新增食物**（五種方式）：
  - **搜尋**：約 50 種常見外食（以「一份」計），加上衛福部資料庫 2,213 種食物（以克數計，可離線）。
  - **條碼**：用相機或照片掃描包裝條碼，向 Open Food Facts 查詢；查不到時照包裝營養標示輸入一次，之後掃描就直接帶出。
  - **套餐**：把常吃的一整餐存成套餐，一鍵加入整組。
  - **自訂**：手動輸入熱量與營養素，可存成「我的食物」。
  - **拍照**：選用的 AI 辨識（需自行部署後端並付費，見下方）。
- **紀錄**：熱量長條圖（7／30 天）與體重折線圖（30／90 天／全部）。
- **體重追蹤**：記錄每日體重、BMI、目標體重；最新體重會自動更新每日熱量目標。
- **資料備份**：匯出／匯入 JSON。
- **PWA**：可安裝到主畫面、離線使用。

## 更新衛福部資料
資料集約每 3 個月更新一次。要更新時：
1. 從 https://data.gov.tw/dataset/8543 下載 JSON 格式（ZIP 壓縮檔），解壓縮到一個資料夾。
2. 在專案根目錄執行：
```bash
python tools/convert_tfda.py 解壓縮的資料夾 kcal-diary/foods-tfda.js
```
3. 把 `sw.js` 的版本號加 1。

## 條碼掃描說明
- Android Chrome 使用瀏覽器內建的條碼辨識；iPhone 等不支援的瀏覽器，第一次掃描時會從 jsDelivr 載入 ZXing 辨識程式（數百 KB，只載入一次）。
- 掃不到時可以「從照片辨識」，或直接輸入條碼數字。
- Open Food Facts 是全球志願者建立的資料庫，台灣商品收錄有限，數值也可能有誤，請對照包裝標示。

## 本機測試
```bash
python -m http.server 5173
```
在 `kcal-diary` 資料夾裡執行，再用瀏覽器開啟 http://localhost:5173 。Service Worker 需要透過 http(s) 開啟，直接雙擊 html 檔不會啟用離線功能。相機掃描需要 https 或 localhost。

## 部署到手機使用
PWA 必須放在 **HTTPS** 網址上才能安裝。把整個 `kcal-diary` 資料夾上傳到以下任一免費服務即可：
- GitHub Pages
- Cloudflare Pages
- Netlify（可直接把資料夾拖曳到網頁上傳）

用手機開啟網址後：
- **Android（Chrome）**：個人設定頁會出現「安裝」按鈕，或從選單選「安裝應用程式」。
- **iPhone（Safari）**：分享 →「加入主畫面」。

> 更新程式後，請把 `sw.js` 裡的 `CACHE` 版本號加 1，手機才會抓到新版。

## AI 拍照辨識（選用、付費）
後端放在 `food-ai-worker` 資料夾，部署方式請看那裡的 README。部署完成後，到 App 的「個人設定 → AI 拍照辨識」填入後端網址與存取碼即可使用。沒有設定時，拍照分頁只能拍照留存，再手動輸入。

## 資料來源與授權
- 食物營養資料：衛生福利部食品藥物管理署「食品營養成分資料集」，政府資料開放授權條款第1版。
- 條碼商品資料：Open Food Facts，Open Database License（ODbL）。

## 注意事項
- `foods.js` 的外食數值是一般常見份量的約略值，實際依店家做法差異很大。
- 所有計算結果僅供參考，有疾病、懷孕或特殊飲食需求時，請諮詢醫師或營養師。
